# Mathematical Statistics – Lab Assignments (AGH, 2023/2024)

Solutions to 12 laboratory assignments from the **Mathematical Statistics** course at AGH University of Science and Technology (Engineering and Data Analysis, 2nd year).
Each notebook covers one topic, from probability distributions to hypothesis testing and ANOVA, and implements the methods in Python. Many estimators and tests are written from scratch rather than called from a library.

> Notebooks are in Polish (course language). 

## Tech stack
Python · NumPy · pandas · SciPy (`scipy.stats`) · Matplotlib · seaborn · scikit-learn (`KernelDensity`) · Jupyter Notebook
